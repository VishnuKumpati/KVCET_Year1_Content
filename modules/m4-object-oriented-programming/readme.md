# Object-Oriented Programming

**M4 . Weeks 9-10 . 8 contact hours**

Classes, inheritance, polymorphism, dunder methods, decorators, and context managers.

---

## Prerequisites

- Completion of every preceding module in this course.
- A working local Python installation, editor, and Git repository.
- All platform exercises from preceding weeks solved and committed.

## Learning Objectives

On completion of this module a learner is able to:

- The limits of loose functions and data, and what classes solve.
- Defining a type and creating instances of it.
- Initializing state and the meaning of the first parameter.
- Data belonging to one object versus data shared by all.
- Controlling access to internal state and the naming conventions used.
- Deriving a class from another and reusing its behaviour.
- Delegating to a parent implementation correctly.
- One interface serving several concrete types.
- Defining a required interface without implementing it.
- Customizing built-in behaviour including operator overloading.
- Wrapping behaviour and managing resources with with.
