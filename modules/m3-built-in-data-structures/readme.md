# Built-in Data Structures

**M3 . Weeks 6-8 . 12 contact hours**

Lists, tuples, dictionaries, sets, strings, comprehensions, generators, and data wrangling.

---

## Prerequisites

- Completion of every preceding module in this course.
- A working local Python installation, editor, and Git repository.
- All platform exercises from preceding weeks solved and committed.

## Learning Objectives

On completion of this module a learner is able to:

- Creating, storing, and inspecting ordered collections.
- Positive and negative positions, and slice notation.
- Adding, removing, and reordering elements in place.
- Fixed sequences, unpacking, and when to prefer them.
- for, enumerate, and zip.
- Constructing lists from expressions and conditions.
- Nested lists as grids and matrices.
- sorted, sort, reverse, and stability.
- Key-value storage, lookup, and insertion order.
- get, keys, values, items, and safe access patterns.
- Uniqueness, membership testing, union, intersection, difference.
- Searching, splitting, joining, cleaning, and case handling.
- f-strings, format specifications, and alignment.
- Lists of dictionaries and dictionaries of lists.
- Building mappings and sets in a single expression.
- Producing values lazily and the memory advantage.
- Anonymous functions and their legitimate uses.
- Transforming, selecting, and ordering by a computed value.
- Cleaning, reshaping, and summarizing real record sets.
