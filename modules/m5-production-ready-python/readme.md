# Production-Ready Python

**M5 . Weeks 11-13 . 12 contact hours**

Files, modules and packages, virtual environments, APIs, pandas, testing, PEP 8, the Git pull-request workflow, and AI-assisted development.

---

## Prerequisites

- Completion of every preceding module in this course.
- A working local Python installation, editor, and Git repository.
- All platform exercises from preceding weeks solved and committed.

## Learning Objectives

On completion of this module a learner is able to:

- Reading and writing text files, modes, and the with statement.
- Reading and writing tabular data with the csv module.
- Serializing and deserializing structured data.
- Splitting code across files and the import mechanism.
- Organizing modules into a package directory.
- os, datetime, math, random, and collections.
- Installing, listing, pinning, and removing third-party packages.
- Isolating project dependencies with venv.
- Reading official documentation to answer a question independently.
- Sending requests and handling JSON responses with requests.
- DataFrames, selection, and basic summarization.
- Status codes, timeouts, retries, and respectful use.
- Writing, organizing, and running automated tests.
- Choosing test cases that actually expose defects.
- Style, naming, structure, and readability standards.
- Recording program behaviour properly instead of printing.
- Feature branches, review, and merging.
- Reading conflict markers and resolving them safely.
- Verification, attribution, and the limits of generated code.
