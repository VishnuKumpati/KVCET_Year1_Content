# Capstone Project

**M6 . Weeks 14-15 . 8 contact hours**

Build, test, document, and ship an individual Python application.

---

## Prerequisites

- Completion of every preceding module in this course.
- A working local Python installation, editor, and Git repository.
- All platform exercises from preceding weeks solved and committed.

## Learning Objectives

On completion of this module a learner is able to:

- Turning an idea into a scoped, testable requirement set.
- Choosing a layout and separating responsibilities.
- Anticipating invalid input, missing files, and network failure.
- Writing a README that lets a stranger run the project.
- Reading and critiquing code against defined standards.
- Completing the README, docstrings, and usage notes.
- Demonstrating working software to an audience.
- Publishing the repository and verifying the delivered state.
