# Programming and Computational Thinking

**M1 . Weeks 1-2 . 8 contact hours**

How code runs, environment, CLI, variables, types, operators, pseudocode, spec-first mindset, and an introduction to Git.

---

## Prerequisites

- No prior programming experience.
- A computer on which software can be installed, or a Google account for the browser-based fallback.
- Ability to read English technical text.

## Learning Objectives

On completion of this module a learner is able to:

- Compilation and interpretation compared, and the consequences of each.
- Source to bytecode to the Python Virtual Machine.
- Python's history, the Python 2 boundary, and where the language is used.
- Installing Python, Visual Studio Code, and Google Colab as a fallback.
- Working directory, paths, and the essential shell commands.
- Assignment, naming rules, and int, float, str, bool.
- print, input, f-strings, type conversion, and commenting discipline.
- Configuring Git and creating a first repository and commit.
- The seven arithmetic operators and the order of evaluation.
- Relational tests and the boolean results they produce.
- and, or, not, and short-circuit evaluation.
- Implicit promotion and explicit conversion between types.
- Breaking a requirement into independently solvable steps.
- Expressing an algorithm before committing it to code.
- Defining inputs, outputs, and edge cases before writing code.
